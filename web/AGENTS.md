# web/

SvelteKit SPA (Svelte 5 runes, plain CSS). Read [../docs/CONVENTIONS-WEB.md](../docs/CONVENTIONS-WEB.md) before editing; the root [AGENTS.md](../AGENTS.md) still applies.

Checks for a change here: `bun run check && bun run build` in `web/`, plus `bun test` and `bun run typecheck` from the repo root (they cover `web/src/**/*.test.ts`).
